# Privacy Policy

**Hermes — Personal Google Workspace Integration**  
Effective date: November 15, 2026

## Operator and scope

This policy describes Nilesh's personal installation of Hermes and its Google Workspace API integration. Contact: [nilesh.datawork@gmail.com](mailto:nilesh.datawork@gmail.com).

This installation is for the account owner's personal use, not a public sign-up service. This policy is specific to that installation; it is not a privacy policy for Google, Nous Research, or other Hermes installations.

## Information accessed

With the owner's Google OAuth authorization and instructions, the integration may access Gmail message contents, metadata and labels; Calendar event details; Drive files and metadata; Docs document contents; Sheets spreadsheet contents; and Contacts details. Access depends on permissions actually granted and APIs enabled.

OAuth access tokens, refresh tokens, and client credentials are used to authenticate API requests. The public information website does not receive these credentials or Google Workspace content.

## Use and AI processing

Information is used to answer the owner's requests and perform requested personal-assistant tasks, such as searching email, preparing summaries, managing files and calendars, and drafting or sending messages. Google Workspace content included in an assistant request may be transmitted to the AI/model provider configured in the owner's Hermes installation and processed under that provider's applicable terms and privacy settings.

This installation is not intended to sell Google user data, use it for advertising, or use it to train generalized AI or machine-learning models. The owner must use provider settings and terms consistent with these restrictions. This page does not assert that third-party providers have a particular retention or training configuration.

## Sharing and disclosures

Google receives API requests needed to provide its services. The configured AI provider may receive relevant content for a requested assistant task. If the owner instructs Hermes to send a message, share a file, or otherwise transmit information, that information is disclosed to the selected recipients or services. Google Workspace content and authorization credentials are not published to this website or repository.

## Storage, retention, and security

Authorization credentials are stored in the owner's local Hermes profile with owner-only file permissions. Retrieved content may remain in local session history, logs, generated files, and backups until the owner deletes it. No automatic content-deletion period is promised. Third-party services may retain information according to their own settings and policies. The owner is responsible for device, account, backup, and model-provider security.

## Revocation and deletion

The owner can revoke this application's access in the Google Account's third-party connections settings. Revocation prevents subsequent authorized API access but does not automatically delete previously saved content. The owner can remove local credential files, Hermes conversation history, logs, generated files, and backups, and use the configured provider's deletion controls where available. Questions or deletion requests can be sent to the contact above.

## Google API data policy

Use and transfer of information received from Google APIs must adhere to the Google API Services User Data Policy, including its Limited Use requirements. Google data is used only for the owner's authorized, user-facing assistant features and is not used to build advertising profiles or train generalized models.

## Website hosting

This static information website is hosted on GitHub Pages. No application-specific analytics, advertising, login, or Google data-collection code is included. GitHub may process ordinary web-request information under its own privacy policies.

## Changes

The operator may update this policy when the installation's data practices change. The effective date above identifies the current version.
